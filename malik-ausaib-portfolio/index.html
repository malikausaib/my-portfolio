I am a 3rd semester engineering student at SRM Institute of Science and Technology (Kattankulathur campus). University life is a whirlwind of lecture halls, lab sessions, late-night code runs, hostel debates, and tea stalls around Potheri and KTR.
Most portfolios try to pretend their author is a senior full-stack architect with twenty enterprise applications under their belt. I'd rather tell the truth: I'm in my foundational years. I spend my time digging through Data Structures and Algorithms in C++, understanding pointer arithmetic and memory layouts, tinkering with JavaScript DOM manipulation without frameworks, and trying to write software that is clean, readable, and intentional.
💡

My philosophy right now: Master the fundamentals before chasing hype. Understand how the memory works, understand why an algorithm runs in $O(N \log N)$ rather than $O(N^2)$, and build websites that respect user speed, accessibility, and typography.

04 ENTRIES RECORDED
01
CAMPUS UTILITY SEM 03 • SRM KTR

SRM Student Resource Hub & Schedule Engine

A lightweight, no-nonsense utility for SRM KTR undergraduates. Unifies quick access to campus portals (Academia, EVarsity, Central Library) with an offline-first timetable organizer and syllabus check-off tracker.

HTML5 Semantic Vanilla JS LocalStorage API

THE MOTIVATION

Navigating different SRM portals between lectures on mobile networks was frustratingly slow. Built this lightweight single-file web tool to store timetable sessions locally and provide immediate 1-tap links without authentication timeouts.

WHAT I LEARNED

Handling client-side persistence with LocalStorage, designing for mobile viewport constraints, and avoiding bulky third-party CSS dependencies.

02
ALGORITHM SANDBOX SEM 03 • DSA COURSEWORK

AlgoVisualizer: Interactive Sorting & Traversal

Visual demonstration sandbox built to explore how QuickSort, MergeSort, and Binary Search Trees operate step-by-step. Includes speed control, array comparison counters, and complexity breakdowns.

C++ Concepts JS Canvas API Algorithm Analysis

THE MOTIVATION

Understanding recursion trees and partition logic in QuickSort was difficult purely through static blackboard diagrams in class. Building the visualizer helped lock in invariant states.

WHAT I LEARNED

Timing functions in asynchronous JavaScript, asynchronous step queues, and mapping algorithmic operations to HTML5 Canvas frame renders.

03
STUDENT TOOLING SEM 02 • PERSONAL

Semester Markdown Notes & Lab Assignment Tracker

A clean, distraction-free markdown scratchpad tailored for coding notes, code snippets, and weekly engineering assignment deadlines. Fast, offline, and keyboard-driven.

Markdown Parser IndexedDB Keyboard Shortcuts

Commercial note apps are overloaded with bloat and slow load times. I needed something that opened in 50 milliseconds during laboratory sessions to paste code snippets.
